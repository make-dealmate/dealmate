# Dealmate 홈페이지

흰색과 코발트 블루, 큰 글자, 단계별 설명을 중심으로 구성한 소개 홈페이지입니다. 선택한 버전과 배포 방법은 [저장소 안내](../README.md)를 참조합니다.

이 폴더에서 `npm run dev`를 실행하면 <http://127.0.0.1:4174/>에서 미리 볼 수 있습니다. 다른 포트는 `npm run dev -- 4175`처럼 지정합니다. Node.js만 필요하며 별도 패키지 설치나 빌드가 없습니다.

`public/`이 홈페이지입니다. 단계 선택은 서비스 구상을 설명하는 화면 전환이며 실제 AI 기능은 아닙니다. 상품 그림과 메모는 설명용 구상도이고 실제 매물, 판매자 답변 또는 실적이 아닙니다.

미리보기 서버는 이 컴퓨터에서만 접근할 수 있습니다. 실제 공개 파일은 `public/`이며 미리보기 서버와 개발 문서는 웹사이트로 제공하지 않습니다.
